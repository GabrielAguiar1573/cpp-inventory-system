\# C++ Inventory System



A simple inventory system developed in C++ as part of my studies in programming and game development.



\## Festures



* Create items with name, quantity and unid weight
* Add items to an inventory
* Display all items in the inventory
* Calculate the total weight of each item
* Calculate the total weight of the inventory



\## Concepts practiced



* Classes and objects
* Header ('.h') and implementation ('.cpp') files
* Constructors
* Encapsulation
* Pointers
* 'std::list'
* Range-based 'for' loops



\## Technologies



* C++
* Visual Studio
* Git and GitHub



\## Running the Project



Open the solution file 'TreinoInventario.slnx' in Visual Studio and build/run the Project.



\## About



This Project was created as a programming exercise to practice C++ fundamentals while studying game development
